# 3D 도서관 페이지와 도서 위치 찾기

- 날짜: 2026-11-06 · 브랜치: `feat/3d-library-page` · 시작 커밋: `9269ec8`
- 크기: M · 어댑터 필수 슬롯 대상: 예(코드 1슬롯. 한국어 UI 문자열 변경이 있어 문서 교정은 선택)
- 상태: release

## 요청 (원문)

> 도서 상세 블레이드 또는 패널에서 '위치'를 누르면 해당 3D 서가에서 해당 서가의 책 위치를 하이라이트 해주는 네비게이션 기능이 필요합니다. 이미 그걸 요구했는데, 해당 브랜치에서 해결이 안되었나 봅니다. (첨부: 상세 패널의 위치 버튼 캡처)

> 각 서가 사이에 사람이 위치할 수 있게 하고, 서가 앞에서 각 서가의 책에 마우스 오버 하면 툴팁으로 책 정보를 보여주면 직관적일 것 같아요. 그런 의미에서 3D 도서관 상세 페이지를 만들어서 초기 화면에서 곧바로 이동할 수 있게 하면 더 좋겠어요.

> 아니면 서가를 클릭하면 해당 서가 앞으로 시점을 이동시켜주고, 다시 전체로 빠져나오게 하는 등의 기능을 추가하는 것도 3D 도서관 상세페이지에 추가하면 더 좋겠네요.

> 이 기능이 추가되면 책 상세 내용을 알려주는 블레이드 또는 패널에서 해당 서가로 이동하게 하는 방법 또는 네비게이션도 구축하는 게 자연스럽게 이어지지 않을까 합니다. UI/UX 전용 에이전트를 통해서 좀 더 개선책을 연구해봅시다.

> (UX 검토의 P0 목록과 기본값 제시 후) 기본값이 제가 생각한 MVP로 딱 적당합니다.

## Architect

- 요구 재진술: 상세 패널의 위치 버튼을 누르면 사용자가 그 책이 3D 서가 어디에 있는지 **눈으로 볼 수 있어야** 한다. 이를 위해 3D 도서관 전용 화면(서가 사이 통로, 서가 앞 시점, 전체 보기 복귀, 책 툴팁)을 만들고 홈에서 바로 들어갈 수 있게 한다.
- UX 검토(독립 서브에이전트, 실행 없이 코드·캡처 검토)의 P0 8개를 범위로 정했다: 좁은 화면 드로어 접기, 넓은 화면 도킹(1240px 이상, 380px), 화면 비율에 맞춘 서가 앞 구도, 시점별 위치 표시, 위치 문장 배너(`role="status"`), 시점별 툴팁과 터치 카드, 전체 보기·Esc·같은 줄 좌우 이동·경로 표시, 예외 상태(서가 미배정, 칸 초과, WebGL 불가, 대출 중).
- 사용자가 승인한 기본값: 칸 코드 `C-2`는 A단이 맨 위, 1번이 왼쪽 / 3D는 한 방(관·층은 경로 표시에만) / 좁은 화면의 하단 막대를 "상세 패널 유지"로 인정 / 대출 중인 책은 반투명 / 주소창 연동은 이번 범위 밖 / PC 우선, 모바일도 동작.
- 결정·불변 규칙 충돌: 없음. Workbook 표 계약, `LibraryRepository`, API는 바꾸지 않는다. 새 npm 의존성 없음.
- 영향 범위: `src/components/library-app.tsx`(탭·드로어·Esc), 새 `src/components/library-3d-page.tsx`, `src/components/shelf-scene.tsx`(재작성), 새 `src/lib/shelf-layout.ts`, `src/lib/i18n.ts`(문구, `fill`, `floorLabel` 이동), `src/app/globals.css`.
