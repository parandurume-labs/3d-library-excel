# 프로젝트 소개(MVP·사회적 영향·AI 가이드)와 한국어 문장 다듬기

- 날짜: 2026-11-07 · 브랜치: `docs/mission-and-korean-polish` · 시작 커밋: `8f834bd`
- 크기: M · 어댑터 필수 슬롯 대상: 예(코드 1슬롯 + 한국어 문서·UI 문자열이 바뀌어 문서 교정 슬롯)
- 상태: release

## 요청 (원문)

> 마이크로소프트 MVP로서 기술의 혜택이 두루 퍼지고, 기술이 포용적인 세상을 만드는 데 기여하게 하는 것이 목표인 점을 상세히 밝히는 표현이 서두에 들어가야 합니다.
> 기술스택과 Microsoft MVP, 사회적영향력(social impact) 등을 강조하는 내용과 UI가 필요합니다. 인공지능은 누가 관리하고 사용하느냐에 따라 달라집니다. 더 많은 기회와 혜택을 더 많이 누릴 수 있는 세상, 풍요로운 세상을 위한 작은 시작이라는 점.
> 그리고 과거와 같이 직접 만들어 사용하는 것이 아니라 인공지능과 함께 활용가능하게 하기 위해서 인공지능을 위한 가이드를 만들었다는 점 등을 좀 더 강조해주세요.
> /duru:proofread 표현이 최대한 어색하지 않고 자연스러우며 한국말의 아름다움을 잘 표현할 수 있게 최대한 고유어도 많이 적절하게 사용해서 문서들을 전부 검토하고 업데이트 해주세요

## Architect

- 요구 재진술:
  1. README 서두에 Microsoft MVP로서의 목표(기술 혜택의 확산, 포용적인 세상), 인공지능은 다루는 사람에 따라 달라진다는 점, 풍요로운 세상을 위한 작은 시작, 인공지능을 위한 가이드를 앞세운다. 기술 스택과 사회적 영향도 따로 보여 준다.
  2. 앱 화면에도 같은 내용을 보여 준다.
  3. 저장소의 한국어 문서와 UI 문자열을 교열·윤문한다. 사용자가 자연스러운 표현과 고유어를 명시해서 요청했으므로 윤문 모드다.
- 결정·불변 규칙 충돌: 없음. Workbook 표 계약, API, 저장소 계약은 바꾸지 않는다. 새 npm 의존성 없음.
- 화면 설계:
  - 사이드바 아래쪽에 있던 동작 없는 "Help & guides" 버튼을 "About & guide"(소개와 가이드) 탭으로 연결한다.
  - 소개 탭(`src/components/about-page.tsx`)은 다섯 부분으로 나눈다.
    - 첫머리: 목표 문장과 Microsoft MVP 배지, 만든 사람
    - 네 기둥: 나눔, 인공지능은 쓰는 사람에 달림, 인공지능과 함께 고쳐 쓰기, 풍요로운 세상을 위한 작은 시작
    - 인공지능을 위한 가이드: 4단계, GitHub의 가이드·소스 링크, 3D 도서관 버튼
    - 사회적 영향
    - 기술 스택
  - 홈 화면 제목 아래에 MVP 배지와 한 줄 소개, "만든 뜻 보기" 버튼이 있는 띠를 둔다.
  - 문구는 `src/lib/i18n.ts`의 `ABOUT_COPY`(en/ko)에 둔다. 가이드는 한국어로만 있으므로 영어 버튼에 "(Korean)"을 붙인다.
- 사실 확인:
  - 만든 사람 이름과 회사는 `LICENSE`의 표기(이인희, 파란두루미)를 따랐다.
  - 사회적 감사 설명은 `LICENSE` 제3조 3.2를 요약했다. 처음 요약은 의무를 부탁처럼 줄여 적어 검수에서 고쳤다(F1).
  - MVP 분야와 연도는 처음에 확인할 수 없어 적지 않았다. 사용자가 MVP 프로필(https://mvp.microsoft.com/en-US/MVP/profile/b4ef6855-0cce-ed11-a7c6-000d3a5603d3)을 알려 주어, 2026-11-07에 그 페이지에서 수상 부문(Microsoft Foundry), 직함(파란두루미 대표), 커뮤니티 역할(Power Platform·Power Pages 한국 사용자 그룹 리더), 프로필 첫머리 문장을 확인해 README와 소개 화면에 넣었다. 활동 연수("5 years in the program")는 해마다 바뀌므로 적지 않았다.
- 검증 계획:
  - 자동 검사: vitest, tsc, eslint, 교정 스크립트(`scan.mjs`)
  - 브라우저: 1440×900과 390×844에서 영어·한국어 화면을 확인한다.
  - 독립 검수: 코드 슬롯과 문서 교정 슬롯을 따로 둔다.

## Implement

- 모드: 기능 + 문서(윤문)
- 변경 요약:
  - `README.md`:
    - 서두를 새로 썼다: "이 프로젝트를 만든 까닭", "이제는 손수 짜지 않고 인공지능과 함께 고쳐 씁니다". 처음에는 "왜 만들었나요", "손수 짜던 시절에서, … 시절로"였으나 사용자가 번역 투로 지적해 고쳤다. 같은 기준으로 "도서관 너머로"(beyond) → "다른 일에도", "~세상을 위한 작은 첫걸음/시작" → "~세상으로 가는 …", "예제로 구현한 재사용 기능" → "이 예제에 담긴, 다시 쓸 수 있는 기능", "표에 대한 영속 읽기·쓰기" → "표에 읽고 쓴 내용이 그대로 남는지"로 고쳤다. "사회적 영향" 표, "기술 스택" 표.
    - 본문 전체의 문장을 다듬었다.
    - 3D 도서관과 소개 메뉴를 기능 목록과 빠른 시작에 더하고, 끝에 "만든 사람과 라이선스"를 붙였다.
    - 사실 오류를 하나 고쳤다. 원문은 앱이 데모로 바뀌지 않는 이유를 "운영 파일에 저장되지 않았다고 오해하는 일을 방지"한다고 적었는데, 이는 뜻이 거꾸로다. "데모 데이터에만 저장된 내용을 운영 파일에 저장했다고 착각하지 않도록"으로 고쳤다.
    - "이번 MVP"(최소 기능 제품)는 Microsoft MVP와 헷갈리므로 "지금 버전"으로 바꿨다.
  - README 분리(사용자 지적 반영): 한국어 본문은 `README.ko.md`로 옮기고, `README.md`는 같은 내용을 영어로 새로 썼다. 두 파일 맨 위에 서로 가는 언어 링크를 두었고, 가이드의 README 링크는 `README.ko.md`를 가리키게 했다. 영어판의 사회적 감사 면제 문구는 LICENSE 영어 원문 (d) EXEMPTIONS와 대조했다.
  - AI 가이드 분리(사용자 요청): 한국어 본문은 `docs/ai-adaptation-guide.ko.md`로 옮기고, `docs/ai-adaptation-guide.md`는 영어로 새로 썼다. 두 파일 맨 위에 언어 링크를 두고, 영어·한국어 README와 앱 소개 화면의 가이드 링크가 각 언어판을 가리키게 했다(`ABOUT_COPY.*.guideUrl`). 영어 버튼의 "(Korean)" 표시는 뺐다.
  - `docs/ai-adaptation-guide.md`(지금은 `.ko.md`):
    - 제목을 "고쳐 쓰는 가이드"로 바꿨다.
    - 사람과 인공지능이 함께 읽는 문서라는 머리말을 붙이고 전체 문장을 다듬었다.
    - 요청문 예시의 내용과 식별자는 그대로 두었다.
  - `src/lib/i18n.ts`:
    - 한국어 문자열 34개를 다듬었다. 예: "대화형 3D 도서관" → "움직여 보는 3D 도서관", "관리자 업무실" → "사서실", "발행연도" → "발행 연도", "권한" → "역할".
    - 알림 문장 세 개는 `제목 + 문구`로 이어 붙여 나오므로 "· 반납해 주세요." 꼴로 바꿨다. 예전에는 "○○ 도서를 반납해 주세요."로 나왔다.
    - `helpGuides`의 영어 값을 "About & guide"로 바꿨다. 키 집합은 그대로다.
    - `ABOUT_COPY`, `REPO_URL`, `AI_GUIDE_URL`, `LICENSE_URL`을 새로 더했다.
  - `src/components/about-page.tsx`(신규), `src/components/library-app.tsx`:
    - `about` 탭을 더하고 사이드바 버튼에 연결했다.
    - 홈 화면에 소개 띠를 넣었다.
    - 소개 화면에서 3D 도서관으로 가면 전체 보기로 시작한다.
  - `src/app/globals.css`: 소개 화면과 소개 띠 스타일, 사이드바 아래쪽 버튼의 활성 표시를 더했다.
  - `src/components/library-app.test.tsx`: 새 테스트 1개를 더했다. 홈 띠와 사이드바에서 소개 화면을 열고, 영어와 한국어 제목, 가이드 링크 주소, 3D 도서관 왕복을 확인한다.
  - `docs/work/2026-11-06-3d-library-page.ko.md`: 사실 오류를 고쳤다. `.gitignore`가 `docs/`를 무시한다고 적혀 있었지만, 실제로는 `docs/playbooks/`만 무시한다.
